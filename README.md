# Katas de SQL

Ejercicios de consultas SQL del **1º de Ciberseguridad**, sobre una base de datos de ejemplo de una aerolínea (reservas, billetes, aviones y vuelos).

## Qué se practica

- Consultas `SELECT` con filtros (`WHERE`)
- Funciones de agregación (`COUNT`, `SUM`, `AVG`…) y `GROUP BY`

## Archivo

- `IntroBBDD.sql`: todas las consultas, comentadas por ejercicio.
